# 星享成长 · 微信小程序开发原型

原生微信小程序 + Node.js 后端 + SQLite 持久化 + 浏览器体验端 + 运营后台。无需第三方运行依赖，无需先申请 AppID 即可运行浏览器开发流程。

“星享成长”为开发工作名称，正式发布前需自行核验名称与品牌权利。

**这是可运行的开发版，不是可以直接上线经营的广告赚钱成品。真实广告、服务端观看验证、现金奖励准入和微信零钱转账尚未完成。** 所有模拟入口、金币、金额和截图均明确标识为开发演示；演示数据不代表真实资金或广告收益。不存在通过填写一个密钥就能自动启用真实支付的开关。

## 本机运行

需要 Node.js 24 或更新版本（使用内置 `node:sqlite`），不需要 `npm install`。

```bash
cd /workspace/vx
npm run setup
npm start
```

在自己的电脑下载源码后，在项目目录执行后两条命令即可。

- 浏览器体验端：本机 8787 端口的 `/`。
- 运营后台：同一服务的 `/admin`。
- `npm run setup` 只在不存在时生成 `.env`，其中有随机 `ADMIN_TOKEN`。从本机文件读取该值登录后台，不要发送到聊天或提交到代码仓库。
- 默认仅监听 `127.0.0.1`。数据库位于 `data/xingxiang.sqlite`，重启不会清空账户和流水。
- 没有默认万能密码；后台令牌仅保存在页面内存中。

## 微信开发者工具

1. 启动后端，导入本项目的 **`miniprogram` 目录**。
2. 目前使用 `touristappid` 进行开发体验；按开发者工具支持的游客方式打开。取得企业 AppID 后再替换。
3. 本机开发的 API 地址在 `miniprogram/config.js`，默认 `http://127.0.0.1:8787`。开发时关闭合法域名校验；项目配置里的 `urlCheck: false` 只适用于开发。
4. 真机不能把手机的 `127.0.0.1` 当成电脑。可信局域网测试时，显式设置后端 `HOST=0.0.0.0`，将客户端地址改为电脑局域网 IP，并按工具能力调试。
5. 正式版本必须配置自己的 HTTPS 合法域名、真实 AppID，并恢复域名校验。不得将开发模拟版直接向公众提供现金奖励服务。

**当前验证没有包含微信开发者工具编译、微信真机运行或真实微信登录网络调用。** 原生客户端已通过 `wx` 适配层与实际 HTTP 后端的契约测试；这不替代微信端测试。

## 已实现

| 模块 | 内容 |
|---|---|
| 日常计划 | 添加、勾选、删除，服务端保存，不依赖广告 |
| 免费签到 | 北京时间每日一次，显示真实近7天签到记录 |
| 可选签到加奖 | 开发模拟任务，每日一次 |
| 宝箱 | 服务端120秒冷却、离开页面继续计时、一个待领取机会 |
| 成长福袋 | 固定奖励、60秒冷却；不提供随机抽奖 |
| 广告开发流程 | 创建任务 → 确认奖励 → 3秒显式演示 → 幂等入账 |
| 金币账务 | 基础奖励、补贴、签到、冻结、退回和模拟完成分开记账 |
| 演示提现 | 金额校验、幂等申请、冻结、审核、驳回退回、模拟完成 |
| 运营后台 | 规则版本、补贴、每日预算、频次、用户限制、审核和审计 |
| 失败恢复 | 保存未完成任务和提现请求编号，回包丢失后查询原任务 |
| 基础安全 | 会话散列存储、账户隔离、管理令牌、请求限流、输入校验、跨站限制 |

初次开发登录获得3600演示金币，专门用于测试提现冻结流程，流水会注明来源。默认1000金币演示换算1元，仅为测试规则，不是运营兑换承诺。后台不允许直接修改换算比例，避免破坏已有账务。

规则修改只影响新任务的奖励金额。任务先预留额度，成功转支出，取消或30分钟过期释放；预算用尽时停止新任务。已创建任务即使在账户被限制后，仍可按原条件完成。当前限制及审计是基础风控，不具备商业反作弊系统完整能力。

## 真实能力的边界

- `AD_PROVIDER=demo`：只在 `APP_ENV=development` 允许。模拟计时只证明开发流程经过3秒，**不证明任何广告真实播放**。
- `APP_ENV=production` 配合 `AD_PROVIDER=disabled`：开发登录、模拟观看、推进计时和模拟付款均被关闭；真实广告任务及提现创建也会拒绝。
- 真实微信登录的服务端交换代码已提供，需配置 `WX_APP_ID` 和 `WX_APP_SECRET`。密钥仅放在服务器，不能放进小程序。真实调用及生产域名需后续验证。
- 没有实现可信广告平台服务端回调，也没有假设微信普通激励接口提供逐次收益、签名凭据或设备商业权重。
- 没有实现微信商家转账下单、通知和对账，`demo_paid` 始终表示“模拟完成，未向微信付款”。
- 尚未实现叠包、随机福袋、实物兑换、邀请返佣、多角色审批、真实客服、注销及完整数据保留流程。
