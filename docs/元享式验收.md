## 已验证的关键流程

- 等待期15秒信息流、45秒横幅错峰位置预览；关闭进入跨类型冷却；前后台与奖励任务互斥、时钟跳变不追赶、次数恢复、正式环境关闭。仅开发预览，非真实广告实测。
- 聊天式群页固定余额/提现栏、五栏导航、悬浮福袋与广告占位关闭可实际操作；注册账户数不冒充在线人数。
- 每种奖励池一张可操作卡，旧金额是历史消息；历史窗口滚出后仍保留当前可领卡。原生页实测暂存/恢复、金额更新后重新显示、领取后新轮次。
- 初始余额0，签到先完成任务；成功只入账一次，基础与补贴分开。
- 红包与宝箱按120秒累计390→780→8888，达到上限不再生成。
- 关闭提示保留叠包，继续等待可以增长；创建任务后锁金额。
- 取消及超时只释放任务新增补贴，保留叠包和对应预算。
- 跨日叠包分别按原预算日期支出，不重复释放或扣减。
- 10个并发HTTP完成请求只成功发奖一次。
- 任务和当前叠包轮次保留原规则，改补贴不追改已创建任务。
- 福袋领取前不暴露结果；概率和结果按任务快照锁定，取消仍受冷却。
- 总次数、分类型次数、个人上限、冷却和账户限制由后端执行，并保留拦截审计。
- 账户受限仍可登录查记录、申诉并完成既有承诺；不能创建新任务。
- 签到与红包所得开发金币可创建演示提现，防重复冻结，驳回只退一次。
- 单层邀请拒绝自邀、改绑、循环和超时补绑；活跃只来自真实成功任务。
- 普通用户不能越权审核或回复；申诉能实际提交和由后台回复。
- 原生客户端完成回包丢失后恢复原任务，不重复发奖或消耗新一轮。
- 错误使用旧产品数据库时拒绝迁移，旧余额保留；新版重启保留叠包。
- 正式模式拒绝开发身份、模拟奖励、开发时钟和模拟付款。
