# 红包封面与“开”字面板

按用户反馈补齐“聊天封面→红包面板→点开→领取结果”的交互。工作品牌仍为悦享金币，使用原创头像与CSS绘制的封口、金币印章，不使用微信标识或其红包素材。

## 现在的操作

1. 群消息里显示紧凑的橙色红包封面、祝福语、待领金币和倒计时。头像、昵称、文案继续来自后台管理的活动助手。
2. 点击封面后创建或恢复原任务，锁定奖励；弹出红色红包面板，显示发送助手、祝福语、基础/补贴/合计，以及金色圆形“开”字按钮。此时没有发奖。
3. 点击“开”才开始现有3秒开发模拟，封口按钮有翻转效果，处理期间防止重复点击。
4. 服务端确认完成后，切到浅金色结果页，显示实际入账金币。“收下，继续叠包”返回群消息。
5. 点右上角×、暂不打开或浏览器Escape会取消当前待确认任务，已叠金币保留。原生离开页面时结束等待确认、恢复底部导航；结果未知时保留原任务查询，不新建第二笔奖励。

红包金额与账务、预算、补贴快照规则沿用后端实现，没有由动画生成金币。宝箱使用相同开封流程与紫色皮肤。签到、福袋保留普通确认面板。所有权益仍为不可兑现的开发金币，真实广告与支付未接入。
