# 群角色、头像与后台消息

本次根据用户补充的交互实现：群页出现多个不同头像与昵称，由后台维护消息内容、顺序和间隔，角色轮流发布文字、金币红包或宝箱消息。角色统一标识为“活动助手”，页面说明其由运营方管理，不冒充真实群友、在线聊天或个人微信转账。

## 实际操作

1. 启动项目，进入同一服务的`/admin`，使用本机`.env.yuanxiang`中的ADMIN_TOKEN登录。不要把令牌发到聊天或提交Git。
2. 找到“群角色与消息管理”。在“活动助手”新增昵称、选择头像、设置排序及启用状态；列表可编辑、停用或删除。
3. 在“轮播消息”选择发布助手、消息类型、文字或红包祝福、距上一条间隔秒数、排序和启用状态。保存后进入发布队列。
4. 前台进入红包群后按服务端时钟发布；停用、删除及新配置在后续轮询中反映。正常轮询间隔5秒，实际出现时间还受网络影响。

头像目前可选6款本项目原创插画；没有实现照片上传或任意外链头像。角色与消息分别最多50个、200条；昵称1—16字、消息1—240字、间隔5—3600秒、排序0—10000。这些是本项目的开发限制，不是微信官方规则。

## 发布节奏与历史

- 消息按排序值、ID稳定排序并循环；间隔表示距上一条发布的前台累计秒数。新配置变更后重新从队列第一条计时。
- 开发预设为6个活动助手与6条消息，首条5秒，后续间隔25、20、30、40、20秒。它是本项目体验参数，不代表元享的真实发布算法。
- 每个账户独立保存活动消息进度。进入或恢复群页时继续计时；离开时暂停。超过10秒没有正常心跳的间隙不补计，每次心跳最多发布一条，不会因离线一天补出大量消息。
- 这是运营内容轮播，不是多人即时聊天，没有公开用户聊天框、伪造群友好评或别人提现消息。助手数量不加入注册账户数，也不计算为在线人数。
- 修改昵称、头像或消息内容影响未来发布；已经发布的记录保留发布时快照。停用或删除角色/消息会撤下其关联活动消息；停用后再启用可恢复可见历史。删除为保留审计的逻辑删除，不对用户金币账务做删除。
- 发布记录写入数据库，重启后仍存在；每账户保留最近100条运营消息，前台读取最近24条，再与个人账务动态合并，展示最近30条及当前待领奖励。操作审计独立保留，生产仍需制定完整隐私与保留期限。

## 红包不会因为多了头像而重复增加

运营消息的节奏与奖励池的120秒累计分别管理。新增一条“金币红包”模板不会直接创造一份金币，更不会冒充其他用户付款。

每个账户仍有红包、宝箱两个独立奖励池。当前消息只关联本账户对应奖励池的当前轮次；每池最多一张可操作卡。较早的红包消息显示为“历史活动消息 · 已合并至当前待领奖励”，没有再次领取按钮。当前轮金额仍由服务器累计、预算预留和任务锁定决定。

关闭卡片保留累计，取消任务保留已叠金币；完成才入账，并开始下一轮。消息被停用或删除时，已有待领金额仍可通过系统卡片继续领取。后台模板无法填写到账金额、替用户完成任务或修改金币流水。

## 技术与权限

新增模块`server/room-content.mjs`负责角色、模板、前台时钟和已发布快照；`server/room-view.mjs`合并活动消息、个人系统事件及当前卡片。浏览器后台`web/room-admin.js`提供实际表单。

新增表：`room_content_meta`、`room_actors`、`room_templates`、`room_clocks`、`room_posts`。仅增加本产品表，不覆盖旧配置、密钥或金币数据。默认数据只初始化一次。

后台API沿用现有管理员鉴权：

| 操作 | API |
|---|---|
| 读取助手、模板、头像选项和内容版本 | GET /api/admin/room-content |
| 新增助手 | POST /api/admin/room/actors |
| 编辑/删除助手 | PUT / DELETE /api/admin/room/actors/:id |
| 新增模板 | POST /api/admin/room/messages |
| 编辑/删除模板 | PUT / DELETE /api/admin/room/messages/:id |
| 前台群页心跳和读取消息 | GET /api/group?active=1 |
| 暂停活动消息时钟 | POST /api/group/presence，active=false |

修改与删除必须携带当前记录version；过期版本返回409，防止覆盖其他操作。前台不能修改助手、模板、顺序或消息状态。所有管理变更进入原有审计。

前台心跳是交互信号，不能证明真人在线、广告展示或有效观看。消息发布不触发广告曝光、收入或金币记账。真实广告、现金场景和微信零钱付款仍未接入；运营角色标识本身不代表整个产品已取得微信许可。
