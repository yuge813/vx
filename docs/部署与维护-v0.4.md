# 安装、配置、备份与部署

## 本机审核

Node.js 24+，无需npm install。Windows双击start-review.cmd，或项目根目录运行：

```bash
npm run setup
npm run doctor
npm start
```

浏览器使用本机8792端口，后台路径/admin。ADMIN_TOKEN只在本机.env.yuanxiang读取；setup重复运行保留现有文件。SQLite实验性提示本身不是启动失败，以实际服务输出及/api/health为准。端口占用时先停止自己启动的旧窗口，或临时设置另一个PORT；不要终止未知服务。

## 原生公开配置

企业AppID与域名获准后可执行：

```bash
npm run configure:mini -- --api https://你的接口域名 --appid 你的企业AppID
```

默认将开发和发布接口都设为该HTTPS源站，并恢复urlCheck=true。可单独用--dev-api修改本地调试地址；HTTP只用于开发工具/可信局域网，需按微信工具实际支持的方式调试。工具只接受公开API地址和AppID，不接收微信密钥。第一次修改会备份config.js及project.config.json为.user.bak，不覆盖未识别的自定义配置。

体验版/正式版配置必须有HTTPS发布地址，客户端会拒绝连接development演示后端。这是安全阻断，不代表配置后就获微信许可。微信密钥只放后端环境，完成合法域名和企业隐私配置后仍需工具/真机验收。

## Docker内部部署

安装Docker后先执行npm run setup生成本机密钥，然后：

```bash
docker compose build
docker compose up -d
docker compose logs --tail=50 app
```

Compose默认只将端口绑定到宿主机127.0.0.1，数据和备份在独立命名卷。镜像使用官方Node24.19.0并固定基础镜像摘要；无运行依赖安装。进程为uid1000，根文件系统只读，/tmp与数据库卷可写，去除Linux capabilities。镜像不包含.env、本机数据库或私有微信工具配置。

当前默认是开发演示，不能直接公开经营。内部远程审核可用SSH端口转发。HTTPS反向代理示例在deploy/nginx.conf.example；替换域名、证书并设置PUBLIC_ORIGIN=https://你的域名。后端按账户限流，外层仍有IP粗限流；Nginx转发头不被当成可信身份。不承诺未经压测的大规模容量。

生产模式必须AD_PROVIDER=disabled，且填写PUBLIC_ORIGIN、ADMIN_TOKEN、WX_APP_ID、WX_APP_SECRET、OPERATOR_NAME、SUPPORT_CONTACT、PRIVACY_URL。配置检查通过也不支持真实广告发金币或真实付款，相关适配和权限仍未完成。

## Linux进程守护

deploy/yuanxiang.service.example提供systemd模板。先创建专用非root用户，将源码置于/opt/yuanxiang，校对Node实际绝对路径和文件权限。代码只读，data与backups目录归服务用户写入；.env.yuanxiang最小权限。模板没有在用户服务器安装或运行。

服务支持SIGTERM/SIGINT关闭，先关闭空闲连接，必要时在5秒后关闭残留连接。资金写入为同步SQLite事务，停止前完成已进入的事务。

## 在线备份与恢复

```bash
npm run backup
# 或指定源和新目标
npm run backup -- data/yuanxiang.sqlite backups/审核备份.sqlite
npm run restore -- backups/审核备份.sqlite data/恢复数据库.sqlite
```

使用SQLite在线备份API，包含WAL中的已提交内容，完成后quick_check，文件权限0600。备份与恢复目标以独占方式创建，已存在的目标或恢复目标WAL/SHM一律拒绝覆盖，不会自动替换运行中的数据库。备份失败时清理本次创建的部分文件。

恢复后停止自己管理的服务，另行备份旧数据，将DB_PATH指向新文件再启动，进入后台核对。不要拷贝运行中的单个主数据库文件当作可靠备份。Docker可在容器内执行node scripts/backup.mjs /app/data/yuanxiang.sqlite /app/backups/指定新文件.sqlite。

## 对账与手工经营记录

后台经营报表检查账户缓存余额对流水、提现冻结/已付、奖励池分日期预留、预算预留和总支出；异常显示差异，不自动改账。该检查不含微信渠道对账。

最终广告结算和现金费用需凭真实账单人工录入，整数分，账单编号幂等。冲销保留原记录及审计；开发金币与人工现金金额分开，不将预览次数当曝光收入。

## 验证和源码归档

```bash
npm run verify
npm run test:browser -- --screenshots
npm run test:ops-browser -- --screenshots
# 已安装Docker且已build镜像时
npm run test:container
# 已验证并提交、工作区干净时
npm run release
```

release只归档Git HEAD中的跟踪文件至dist，附版本、完整提交SHA和源码ZIP的SHA-256清单；忽略密钥、数据、备份和未提交内容。GitHub下载时确认选择codex/yuanxiang-v1-review分支，勿下载旧菜谱分支。
